# Лабораторная работа №5: Клиент-серверное приложение для управления коллекцией вариант(6511)

Разделить программу из лабораторной работы №5 на клиентский и серверный модули.  
Серверный модуль должен выполнять команды по управлению коллекцией.  
Клиентский модуль - в интерактивном режиме считывать команды, передавать их на сервер и выводить результаты.

## Требования

- Операции обработки объектов коллекции реализовать с помощью **Stream API** и лямбда-выражений.
- Объекты между клиентом и сервером передавать в **сериализованном виде**.
- Объекты в коллекции, передаваемой клиенту, должны быть **отсортированы по размеру**.
- Клиент должен корректно обрабатывать **временную недоступность сервера**.
- Обмен данными — по протоколу **TCP**.
- На сервере для обмена данными использовать **потоки ввода-вывода**.
- На клиенте использовать **сетевой канал** в **неблокирующем режиме**.

## Обязанности серверного приложения

- Работа с файлом, хранящим коллекцию.
- Управление коллекцией объектов.
- Назначение автоматически генерируемых полей объектов.
- Ожидание подключений и запросов от клиента.
- Обработка полученных команд.
- Сохранение коллекции в файл:
    - при завершении работы приложения;
    - при исполнении специальной команды, доступной **только серверу** (клиент такую команду отправить не может).

### Модули сервера (в одном или нескольких классах)

- Модуль приёма подключений.
- Модуль чтения запроса.
- Модуль обработки полученных команд.
- Модуль отправки ответов клиенту.

> Сервер работает в **однопоточном режиме**.

## Обязанности клиентского приложения

- Чтение команд из консоли.
- Валидация вводимых данных.
- Сериализация команды и её аргументов.
- Отправка команды и аргументов на сервер.
- Обработка ответа от сервера (вывод результата в консоль).
- Команда `save` из клиентского приложения **убрана**.
- Команда `exit` завершает работу клиентского приложения.

> **Важно!** Команды и их аргументы должны быть объектами классов.  
> Недопустим обмен "простыми" строками. Например, для команды `add` нужно сформировать объект, содержащий тип команды и объект, добавляемый в коллекцию.

## Дополнительное задание

Реализовать логирование различных этапов работы сервера (начало работы, получение нового подключения, получение запроса, отправка ответа и т.п.) с помощью **Java Util Logging**.
